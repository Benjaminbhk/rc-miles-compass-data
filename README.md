# rc-miles-compass-data

Fil de données public de [RC-Miles Compass](https://github.com/Benjaminbhk/rc-miles-compass),
un assistant non officiel pour cartes de crédit HSBC Hong Kong.

**Ce dépôt est généré automatiquement — ne rien y éditer à la main.** Il est régénéré par les
GitHub Actions du dépôt principal, à partir des pages publiques de `hsbc.com.hk` et
`redhotoffers.hsbc.com.hk`.

| Fichier | Contenu | Rafraîchi |
|---|---|---|
| `merchants.json` | marchands désignés par carte et par catégorie | chaque lundi |
| `offers.json` | offres Red Hot Offers en cours | chaque nuit |

Données publiques HSBC reproduites à titre indicatif. Projet non affilié à HSBC.
